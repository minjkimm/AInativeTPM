# Developer Ecosystem Operations

A sample operations dashboard for turning portfolio activity into outcomes, decisions, regional learning, and repeatable practice.

[View the live dashboard](https://developer-ecosystem-ops-prototype.minji391.chatgpt.site/)

## What it demonstrates

- An executive view of activations, budgets, risks, and ownership.
- An outcome register and living activation handbook for regional reuse.
- A decision-focused weekly operating review.
- An executive copilot that answers questions from the dashboard data.
- Clearly labeled sample data when live systems are not connected.

## Data and privacy

All names, events, budgets, risks, and metrics included in this repository are synthetic. No employer data, production credentials, or confidential documents are included.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Hosting

The live application is hosted on ChatGPT Sites. This repository contains its source code. The application uses server-side routes, so it is not deployed through GitHub Pages.
